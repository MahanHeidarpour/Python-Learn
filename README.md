# Python Learn — نسخه‌ی اندروید

⚠️ واقعیت فنی: ابزار ساخت APK (به اسم Buildozer) روی خود ویندوز اصلاً نصب و اجرا نمی‌شه — نه من می‌تونم دور بزنمش، نه هیچ ترفند دیگه‌ای هست. اما یه راه هست که **کاملاً روی ویندوز بمونی و اصلاً Linux نصب نکنی**:

## راه‌حل: ساخت APK روی سرورهای گوگل/گیت‌هاب (GitHub Actions) — رایگان
به‌جای این‌که خودت لینوکس نصب کنی، فایل‌های پروژه رو می‌فرستی به گیت‌هاب، و خودِ گیت‌هاب روی سرورهای خودش (که لینوکسه، ولی تو اصلاً باهاش کاری نداری) برنامه رو می‌سازه و یه فایل APK آماده بهت تحویل می‌ده. تو فقط با مرورگر (Chrome) کار می‌کنی، دقیقاً مثل کار با جیمیل.

از قبل یه فایل به اسم `.github/workflows/build.yml` داخل پروژه گذاشتم که این کار رو خودکار انجام می‌ده.

---

### مرحله ۱ — ساخت اکانت گیت‌هاب
برو به github.com و یه اکانت رایگان بساز (اگه نداری).

### مرحله ۲ — ساخت یک Repository جدید
1. روی دکمه‌ی سبز «New» یا «+» بالای صفحه بزن → «New repository»
2. اسمش رو بذار مثلاً `python-learn-app`
3. گزینه‌ی Public رو نگه دار، روی «Create repository» بزن.

### مرحله ۳ — آپلود فایل‌های پروژه (بدون نیاز به دستور، فقط درگ‌ودراپ)
1. داخل صفحه‌ی repository که ساختی، روی لینک «uploading an existing file» کلیک کن.
2. تمام فایل‌ها و پوشه‌های داخل `python_learn_android` (همونایی که براتون فرستادم) رو انتخاب کن و بکش داخل صفحه (Drag & Drop) — از جمله پوشه‌ی مخفی `.github` رو هم حتماً آپلود کن (اگه ویندوز نشونش نمی‌ده، تنظیمات Explorer → View → Show hidden items رو بزن).
3. پایین صفحه دکمه‌ی سبز «Commit changes» رو بزن.

### مرحله ۴ — دیدن ساخت خودکار APK
1. بالای صفحه‌ی repository، روی تب «Actions» بزن.
2. می‌بینی یه پروسه به اسم «Build Android APK» خودش شروع شده (چون فایل build.yml رو آپلود کردی).
3. صبر کن (۱۵ تا ۳۰ دقیقه طول می‌کشه). یه علامت ✅ سبز نشون می‌ده که تموم شده.

### مرحله ۵ — دانلود فایل APK
1. روی همون اجرای سبز‌شده (Build Android APK) کلیک کن.
2. پایین صفحه، بخش «Artifacts» رو پیدا کن، روی `PythonLearn-apk` بزن تا دانلود بشه (یه فایل zip میاد که فایل apk توشه).
3. فایل apk رو با تلگرام/درایو/کابل به گوشی اندرویدت منتقل کن، روی فایل بزن، اجازه‌ی «منابع ناشناس» رو بده، و نصبش کن.

بعدش آیکون **Python Learn** روی گوشیت میاد. ✅

## اگه بعداً خواستی درس اضافه کنی
فایل `lessons.py` رو ویرایش کن، دوباره تغییرات رو توی همون صفحه‌ی گیت‌هاب آپلود/ذخیره کن (Commit) — خودش دوباره APK جدید می‌سازه.
